# 文档

- `notes/`：科研笔记，按日期命名，记录每次实验的设置、结果、分析和下一步。
- `paper/`：论文草稿（`abstract.md`）与相关工作、审稿质疑（`related-work.md`）。
- `metric-maintenance-report-2026-09-30.md`：指标口径维护实验汇报（维护方式对照、共享度扫描、端到端 LLM 实验）。
- 设计与协议：`metric-experience-protocol.md`（指标经验）、`research-protocol.md`（2×2 消融）。
- 早期验证报告：`research-results-2026-09-28.md`、`real-data-validation.md`、`deepseek-real-validation.md`。
- 实验数据在仓库根目录的 `exp/`，每次实验一个目录，索引见 `exp/README.md`。
