## 结论与证据

| 主张 | 已运行的证据 | 可以支持的范围 |
| --- | --- | --- |
| 减少用户侧智能体的重复摸索 | 三个生产者流；四方法在相同业务定义、共同来源历史下比较。恢复轮 216 次主分析和 48 次命名次要尝试，无服务失败。持续积累比隔离输入 token 低 **24.4%**、结构查找低 **27.7%**，比首轮冻结输入低 **18.9%**；主分析四组均 **54/54** | 已建库消费者的探索成本；一个合成领域、一个返回模型名约束、三个流的描述性结果。消费者不训练记忆，不含来源采集，不支持准确率优势或一般规划进化 |
| 新知识能帮助后续智能体 | 冻结首轮与持续积累对比，精确前缀归档，消费者写回逐题重置；三个流的积累／隔离输入 token 差为 −28.5%、−24.4%、−20.3%。命名题隔离 3/12、冻结 6/12、积累和轨迹均 12/12 | 主比较识别知识覆盖后的复用收益；命名题另外包含业务信息差异，不能与主比较混合 |
| 执行反馈能选择更便宜的策略 | 三轮同负载实际 PostgreSQL 计时；64 个不同表对按 24/16/24 分训练、采纳证据和测试。需要补键时 0/3 采纳；修复备选耗尽及交替时回放代价低 61.9% 和 37.9%，判定一致 | 仅验证顺序的反事实回放，选择与测试集回顾最优固定顺序相同。完整检查采集 38.52 秒、含建表 72.63 秒；不证明净部署收益、工作流进化或漂移适应 |
| 维护表／字段／关系知识 | 六步真实 HTTP 诊断：画像首次两条探查，新智能体复用零新增探查；通知 DML 后行数刷新。注释和新增列定义在进程内过期，新增列名已在样例中可见，重启后定义与注释更新。已有维护回放另外检验关系、粒度、时间条件、修复及并发 | 可复用类型、注释、样例、统计和经验证关系；**尚未实现完整实时目录刷新、业务词表同步及每字段的独立语义维护**。结构条件不能证明单位、业务总体或连接完备性 |

来源学习与提炼累计 **343.6 秒、277.2 千 token**，另报，不含建表及外部判题 SQL。消费者时间从首次模型调用到答案，不含中间层构造和快照恢复；模型工具循环在进程内调用，HTTP 传输另测。

## 原始失败、代码与验证

原按量线路另有完整 264 次尝试，其中 28 次 HTTP 402（主分析 19、命名 9）。实际返回的 197 个主分析答案全部正确；错误路径的 token／轮数是下界。恢复是在原轮审计后，仅因服务不足决定，沿用相同二进制、端点、返回模型名校验和预算，重新生成全部生产者及消费者。两轮不合并；事后完成调用敏感性分析单列，不能替代原始全部尝试。

运行时源码、二进制摘要、逐工具轨迹、12 个前缀／轮、所有失败及清理结果均归档。原轮和恢复轮的 29 个源码／协议／启动文件分别匹配归档摘要；策略实验的 28 个代码文件同样匹配。早期策略协议未完整存档，不声称已恢复。统计、表格、坐标重新生成后逐字节一致，见 [往返核对](../exp/2026-10-03-shared-memory/analysis/source-and-roundtrip-verification.json)。额外十进制复核确认两轮返回的主分析答案都在题面精度内；SQL 探查分类是代理指标，[复核记录](../exp/2026-10-03-shared-memory/analysis/classification-review.md)由 Codex 完成，不能称为独立人工标注。

最终审查修复两处问题：反向连接可能重复累计事实金额；条件比较及过滤去重曾合并字符串值的大小写和空格。新原型拒绝反向、多跳和自连接，保守比较保留字面量，并通过真实数据库反例：100 被错误累计为 200；不同过滤总体具有不同唯一性。两轮最终前缀的 25 个指标条目全部满足新方向约束，相关过滤未触发旧字面量合并问题。补丁在实验后完成，实验时源码保持原样，不声称数据由最终修正版重跑。
