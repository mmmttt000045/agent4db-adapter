# 2026-10-08 生命周期实验：一个共享库在持续到来的使用者与累积的数据更新下

外部评审（10-08）建议：“保留一个库，持续到来消费者和数据更新，记录累计正确完成任务、tokens、维护工作、等待时间，以及不同修订的采用情况”，回答“随着使用者和更新不断增加，共享层是否持续减少重复工作，而不是只在重置后的单个场景里有效”。用户同意做（“可以跑一个一个共享库在持续到来的使用者和数据更新下走完生产、复用、失效、修复、优化的全过程”）。

## 设计（`metric-bench --lifecycle`，提交 b1c5974）

- 每个方法一个进程、一个隔离库（100 万行门店销售），各自从 v1 开始；时间线上的更新累积、不回滚。
- 生产：A 用带口径题面学习 10 道学习题，提炼、准入（MAVRA）或保存轨迹（示例检索）；MAVRA 随后一轮优化（规则候选优先，无规则候选发布时请模型提议）。
- 时间线（默认）：`none, append, status, revision, dimhist, rekey, dupload, cleanup, correct`。每一步：
  1. 施加更新：先改业务事实并计算标准答案，再改数据表示（与场景评测相同）；`cleanup` 删除此前重复装载的完全相同的副本（保留版本化更正的旧版本行，`scenario::cleanup_duplicate_load`）。
  2. 按需生产（只 MAVRA）：上一波之后没有任何有效定义的指标，由 A 在当前数据上重新学习、提炼、准入，之后再做一轮优化。
  3. 一波新使用者：15 道计分题（5 个指标 × 新期间 / 跨期差值 / 按月排名），每题一个新的智能体（U{步}-{序号}），2 个同时进行；维护照常在首次使用时发生，同时到达的请求合并等待。
- 方法：`metric-global-full`（MAVRA 完整配置：条件级维护、学习时快照上的回归、优化修订、同快照执行与事务性表版本）、`traj-global`（示例检索）、`middle`（无记忆）。
- 选这条时间线的原因：标准答案 SQL（带 `sr_status`、`ss_is_current`、`i_is_current` 过滤）在这些累积变化下仍然正确；`latekey`、`unit`、`mirror` 的标准答案在累积数据上无法用同一 SQL 计算，所以不在时间线上（它们在逐场景评测中已覆盖）。`dupload` 一步的标准答案在施加重复之前计算。
- 已知限制：学习时快照库只有 v1；第 7 步重新学习的定义若之后再修复，as-of 回归会在 v1 上比较（本时间线中重新学习之后只有正常的原地更正，不触发修复）。

## 命令（noctis）

```
OUT=results/life-20261008
for mode in metric-global-full traj-global middle; do
  ./target-life/release/agentdb-mid --pool 8 --out $OUT/$mode metric-bench --agent cline --extractor cline \
    --modes $mode --metrics M1,M2,M3,M4,M5 --phrasings named --repeats 1 --rows 1000000 --sql-timeout-secs 120 \
    --lifecycle --concurrency 2
done   # 三个进程相隔 60 秒并行启动，CLINE_REASONING_EFFORT=high
python3 tools/lifecycle-stats.py --mavra <cell> --traj <cell> --none <cell> --tex-out overleaf/gen --json lifecycle-stats.json
```

- 每题 token：MAVRA 28.3k，检索 18.0k，无记忆 37.5k；每个正确答案（含建立、重新学习与模型优化提议）36.2k / 23.2k / 85.2k。重复装载之前 MAVRA 每题 12.9–15.5k、3.9–4.2 轮（检索 12.3–21.1k、4.3–6.1 轮）；重复装载一步 MAVRA 114k/题（失效后使用者自行探索，与 §7.7 的负结果一致），检索 23k 但答对 9/15，之后两步检索仍为 9/15（过期示例），MAVRA 12、13。

- 重复装载之前每个使用者都声明了所用修订（100%）；同快照执行没有拒绝（波次期间没有并发写入）；维护等待/合并 12 次；维护数据库时间合计约 246 秒（以修复搜索为主）。
- 审计标出的“执行了不正确的修订”5 次全部是退货率 r3 在跨期差值题上：学到的度量是 `ROUND(SUM(...)/SUM(...)*100, 2)`（提取器把题面的“保留两位小数”写进了度量），差值题先各自取整再相减，更正之后两个月取整相同，答成 0.00（标准 0.0076）。这是学到的定义本身的缺陷，不是维护问题（没有条件被破坏）；论文不报告这个计数。
