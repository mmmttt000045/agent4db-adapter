\begin{abstract}
\bi{Data agents repeatedly explore the same database, spending LLM calls on calculations and structural assumptions discovered in earlier sessions. We present \system, a shared memory layer that turns successful explorations into executable metric and feature definitions and maintains them as data evolve. Each definition couples reusable computation with checkable data conditions and learning evidence. Publication checks validate extracted definitions; compilation instantiates them for new questions and prediction instances. Snapshot-bound metric execution checks conditions on the consuming snapshot. Shared condition results, repairs, and equivalent rewrites amortize validation, maintenance, and optimization across agents. On a TPC-DS workload with \PpAgents\ agents, \system\ reduces tokens by \PpMavraTokSaveNone\% relative to no memory and by \PpMavraTokSavePrivate\% relative to private memory with the same mechanisms. After a data restatement, accuracy is \PpMavraChangeAcc\% versus \PpNoneChangeAcc\% without memory. In the five-cutoff RelBench study, reuse-stage tokens decrease by \RbStackMavraTokSave\% on rel-stack and \RbTrialMavraTokSave\% on rel-trial relative to no memory, while all six tasks retain baseline predictive quality within the evaluation margins. Including initial learning and memory operations, full-sequence tokens decrease by \RbStackMavraTokSaveAll\% and \RbTrialMavraTokSaveAll\%. These results demonstrate the benefits of sharing executable knowledge and its maintenance across data agents.}
{数据智能体反复探索同一数据库，花费大模型调用重新发现此前会话已获得的计算逻辑与结构前提。本文提出共享记忆层 \system，将成功探索转化为可执行的指标与特征定义，并随数据演进持续维护。每条定义将可复用计算同可检验的数据条件及学习证据结合。发布检查验证提取结果，编译为新问题与预测样本实例化定义；快照绑定的指标执行在消费快照上检验条件。共享条件结果、修复与等价改写，将验证、维护及优化开销分摊到多个智能体。在\PpAgents{}个智能体的TPC-DS负载上，\system\ 相对无记忆减少\PpMavraTokSaveNone\%的token，相对采用相同机制的私有记忆减少\PpMavraTokSavePrivate\%。数据更正后，正确率为\PpMavraChangeAcc\%，无记忆为\PpNoneChangeAcc\%。在五截点 RelBench 实验中，相对无记忆，rel-stack 与 rel-trial 的复用阶段 token 分别减少 \RbStackMavraTokSave\% 与 \RbTrialMavraTokSave\%，六项任务均在评估容差内保持基线预测质量。计入初始学习与记忆操作后，全序列 token 分别减少 \RbStackMavraTokSaveAll\% 与 \RbTrialMavraTokSaveAll\%。这些结果展示了在数据智能体之间共享可执行知识及其维护工作的收益。}
\end{abstract}
