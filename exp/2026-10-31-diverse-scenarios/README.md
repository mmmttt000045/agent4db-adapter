# Fig.6：受检指标执行与跨智能体题型迁移

本批保留合成零售和 TPC-H SF1、每库 M1/M3/M5 三指标及全部十一类独立变化，增加期间差值、最高月份、最大月度增幅三种 M3 题型，交给新的智能体 B 作答。每个方法都获得相同的显式业务定义；B 的近期结果反馈从空开始。ACE/AWM 保留智能体私有记忆，G-Memory 保留库内共享，MAVRA 保留全局指标定义。新增题是针对共享语义与聚合执行的机制测试，不能推广为未见基准上的普遍领先。

## 正式比较与数量

已完成并关闭新增调用：两格 MAVRA 原题库重跑、八格新增题补测及全部原始记录核验通过。累计实际扣费 **19.72 元**，保守计价上界 **19.74518594 元**；共 7,090 次历史及本批 API 调用均计入。

`paired-reuse-protocol.json` 固定复用此前有效批次的全部六个未变更基线格，重跑发生改变的 MAVRA 两格。原对照位于 `results/corrected-scenarios-20261031/`，来源归档哈希为 `dfe1e2fb3ed6f4c6f86417bdbfa97cfd0c01999e7dabb5129c460dfa61b8e320`。没有按准确率选取对照。旧批次的 MAVRA 结果不进入新分数，其费用仍计入累计账本。

原题库每个方法共有 46 次计分问答，跨两库共有六道不同计分问题。本批再增加每库三道不同问题，四方法共同增加 24 次计分问答。最终比较为 **12 道不同问题、208 次计分问答、48 次学习，共 256 个正式任务**；72 次缓存源任务只用于恢复，不重复计分。题型由单期扩展为四种；未执行的第五种 above-mean 仅为准备好的候选，不能声称已测。

原留出、正常更新四类、覆盖变化五类、单位、备份来源及新增题分支共 13 个情形各占相同权重；组内先按各情形正确率取平均。图展示正常更新、覆盖变化、跨智能体迁移及全部情形，仍为单栏 84.6 × 55 mm、双面板、32 根柱。原留出与单位／备份失败继续计入总体。一轮／方法、复用冻结对照，不画置信区间，不声称统计显著。

## 结果与边界

两模式和全部 13 情形等权汇总的描述性正确率为：**MAVRA 84.6%、AWM 81.4%、ACE 73.1%、G-Memory 61.5%**。直接按全部题次计数，分别为 **43/52、41/52、38/52、32/52**；MAVRA 在两种汇总下都最高。该联合描述在实验完成后增加，不是新的预注册终点；所有分库、情形、方法和失败均保留，没有重算或替换任何原始成绩。一次运行不支持统计显著性声明。

合成数据全部情形：MAVRA **92.3%**，ACE 76.9%，AWM 74.4%，G-Memory 38.5%；MAVRA 领先最强基线 **15.4 个百分点**。TPC-H 全部情形：MAVRA **76.9%**，ACE 69.2%，AWM 88.5%，G-Memory 84.6%；总体仍落后于 AWM。两库覆盖变化均为 80.0%，分别与 AWM、G-Memory 并列。

新增六题：MAVRA、AWM、G-Memory 均为 **6/6**，ACE 为 5/6。MAVRA 使用 **19 次官方调用、76,643 token**，调用最少且总 token 最少的基线 AWM 为 30 次、114,985 token，分别减少 **36.7% 和 33.3%**。计入所有正常在线记忆更新，对每种方法都排除原有源学习；这是完整方法的边际复用成本比较，不是结构化表示的单独消融。TPC-H 新题上 MAVRA token 还略多于 AWM（每题 11,450 对 10,616），两库合计优势不能写成每库均节省。

MAVRA 的合成失败仅为三道日期键变化题；TPC-H 仍有追加两题、日期键两题、单位两题失败。TPC-H 追加中 `run_metric` 已返回正确的双倍总额，消费者又按相似载荷去重、忽略新的业务键，导致最终答案减半。原始错误答案完整保留，不能用正确的中间 SQL 结果替换最终作答。细节见 `case-evidence.json`，所有分项与费用见 `summary.md`。

## 问题选择、状态恢复与反馈

`extra-protocol.json` 固定新增题的顺序为差值、最高月份、最大月度增幅、超过均值的月份数。`paired-reuse/extra-decision.json` 只使用剩余预算及预先固定的用量预测，选择前三题；四题方案不满足费用门槛。选择发生在新增付费作答前，不使用正确率。三题题单在 `reuse-banks/{synthetic,tpch}-extra3/`，原题库在对应 `-base/`。较早的 `question-banks/*-m*` 属于失效的开发批次，不能作为最终计分题单。

各额外分支恢复原运行的学习六题及留出三题后的状态。`source-cache-front.py` 只重放此前已付费的九题源响应；未命中源响应会停止，不能悄悄发起新调用。`seed-memory-service.py` 核对源动作、标量答案与正确性，恢复原手册、工作流或 G-Memory 存储，在检查点之后才启用真实 API。原生方法还重放其提炼／优化响应。免费检查覆盖六个基线与两个原生格，每格源九题和四个假模型额外题；这些检查不提供科研正确率。

缓存基线的源规划提示词与原运行逐项一致；未计分重放时 `dispatch` 的辅助 `common_feedback` 元数据为空，在检查点恢复真实状态。规划器读取的是原 `system_prompt`，该辅助字段不进入规划。新增付费题的提示词和反馈元数据均按 B 自身最近三题实际结果核对。A 的反馈不转给 B。所有方法都不接收参考答案、参考 SQL 或隐藏变化标签，已发表方法保留正常更新。

## 实现与验证

修复指标编译器：过滤表达式中的裸列按所属表限定，避免多个表都含 `is_current` 时 G7 失败；AST 处理保留字符串与函数含义，拒绝多语句。新增 `run_metric` 按已发布业务定义及本题参数编译并执行，沿用修订、快照和 SQL 审查，失效或过期修订不能执行。原语义保留修复继续有效。

57 项 Rust 单元测试与发布版 PostgreSQL 回归通过，八项既有测试忽略。回归覆盖同名过滤列、新增不同业务键但相同载荷的 80→160 总额，以及失效／旧修订拒绝。调试构建曾超过默认线程栈；增大调试栈及生产发布版默认栈均通过，遗留测试库已核查清理。免费完整工程检查还验证 assistant／tool／final 轨迹、reasoning 回传和 ACE/AWM/G-Memory 实际更新输入。上述测试不替代真实模型评估。

MAVRA 原题库使用冻结主二进制 SHA-256 `aa7dcc4bb7f5c175962247a55a4dd933943d1d36fb96921456c076cad7283abb`。额外消费者选项单独编译为 `agentdb-extra`；主二进制未覆盖。所有格使用 `FIG6_LEGACY_SHARED_PROMPT=1`，保持共用规划提示词与旧对照一致；新增的指标工具说明是原生方法的一部分。
