# MAVRA：面向数据智能体的共享指标定义维护

English title: **MAVRA: Maintaining Shared Metric Definitions for Data Agents**

> 当前中文摘要，从 main.tex 自动提取（数值宏已展开，来自 gen/numbers.tex）。

大语言模型数据智能体通过探索表结构、探查取值和编写 SQL 回答业务问题。这一过程高度重复：在我们的轨迹中，全新的智能体会话把三分之二的数据库调用用于查找，其中 93% 的查找重新获取了此前会话已经得到的事实；应用负载重复的则是稳定的查询模板。共享智能体学到的指标定义可以消除这类重复并保持答案口径一致，但也使每个定义成为变化数据库上的长期状态。定义的 SQL 只在一些 SQL 本身没有写明的数据性质成立时才正确：过滤后的键对应一条业务记录，连接不放大行数，日期按预期角色关联。纯数据更新可以在不改表结构的情况下破坏这些性质，查询照常执行，却静默返回错误的汇总值。本文提出 MAVRA，一个把可执行有效性条件作为共享指标定义维护单位的中间层。MAVRA 只准入从判题成功轨迹中提炼的定义，按依赖版本索引定义的条件，只重查依赖表发生变化的条件，跨定义和智能体复用条件结论，对失效定义撤销并做经过回归测试的修复，并在执行端核对声明的定义修订。在 19 个定义、8 个智能体的受控实验中，正确性相同时，条件级维护的数据库时间在错峰到达时为定义级重验证的 12.5–37.8%，同时到达时为 44.6–75.5%。在 10 种数据变化场景和 3 个大模型上，维护后的共享定义把正确率从不共享时的 32% 提高到 74%，在已建模的破坏性变化下从不使用过期定义，而只看结构的维护和无守护共享分别在 195 和 201 道题中使用了过期定义；其维护数据库时间为定义级重验证的 49%。
