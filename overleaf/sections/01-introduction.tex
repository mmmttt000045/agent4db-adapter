\section{\bt{Introduction}{引言}}
\label{sec:introduction}
\bi{Data agents repeatedly explore the same database to answer different questions and build predictive features. An agent asking for March revenue, another asking for September revenue, and a third asking for quarterly revenue all need the same measure, grain, filters, and joins. When each session discovers these independently, the workload pays repeatedly for schema inspection, value probes, join tests, and the LLM calls that plan and interpret them. In our traces of 100 memoryless metric sessions, 93\% of lookups repeat a fact obtained by an earlier session, and 71\% of session time precedes the answer query. Public benchmark tasks exhibit the same overlap in calculations and domain knowledge (Section~\ref{sec:workload-characterization}).}
{数据智能体为回答不同问题和构建预测特征，会反复探索同一数据库。询问三月收入、九月收入和季度收入的智能体，都需要相同的度量、粒度、过滤与连接。如果每个会话独立发现这些知识，整个负载就要反复支付模式检查、取值探查、连接验证，以及规划这些操作和解释结果的大模型调用开销。在我们的 100 个无记忆指标会话轨迹中，93\% 的查找重复此前会话获得的事实，71\% 的会话时间发生在答案查询开始之前。公开基准中的任务也表现出计算规则与领域知识的重叠（第~\ref{sec:workload-characterization} 节）。}

\bi{We present \system\ (\textbf{M}etric-\textbf{A}ware \textbf{V}alidation and \textbf{R}euse for \textbf{A}gents), a shared memory layer between data agents and the database that reduces repeated exploration, token consumption, and end-to-end time. Figure~\ref{fig:metric-record} contrasts independent sessions with this shared layer. Successful sessions contribute database knowledge; later agents retrieve it and obtain SQL for their own periods or prediction instances. Knowledge accumulates around the database and serves multiple agents, tasks, and sessions. A new consumer can therefore use discoveries made by previous consumers, amortizing learning over the workload.}
{本文提出 \system{}（\textbf{M}etric-\textbf{A}ware \textbf{V}alidation and \textbf{R}euse for \textbf{A}gents），一个位于数据智能体与数据库之间的共享记忆层，用于减少重复探索、token 消耗和端到端时间。图~\ref{fig:metric-record} 对照独立会话与共享层两种路径。成功会话贡献数据库知识，后来的智能体检索这些知识，获得适用于自身期间或预测样本的 SQL。知识围绕数据库持续积累，服务多个智能体、任务和会话；新使用者因此能直接利用此前使用者的发现，把学习开销分摊到整个负载。}

\bi{The layer stores executable metric and feature definitions, together with table descriptions and verified join paths. A definition captures a measure, its grain, joins, and required filters; feature definitions additionally encode the entity and temporal window. Compilation binds these objects to a new question or seed table. On a definition hit, compilation bypasses repeated schema, value, and join exploration, shortening the sequence of LLM and tool calls and the contexts processed by those calls. Our cost model makes the effect explicit: as more questions reuse a learned definition, the initial discovery and publication cost is spread over more uses, and per-question cost approaches the cost of reuse (Section~\ref{sec:alternatives}).}
{共享层保存可执行的指标与特征定义，以及表描述和经验证的连接路径。定义包含度量、粒度、连接与必需的过滤；特征定义还包含实体和时间窗口。编译过程将这些对象绑定到新的问题或种子表。定义命中后，编译省去重复的模式、取值与连接探索，缩短大模型和工具调用序列，并减少这些调用处理的上下文。代价模型明确刻画这一效果：复用某个已学定义的问题越多，初始发现与发布开销就由越多次使用分摊，每题代价逐渐趋近复用代价（第~\ref{sec:alternatives} 节）。}

\bi{The shared layer also improves and maintains answer correctness. Publication checks verify extracted definitions before other agents use them. Conditions derived from grain and joins are checked on the consuming query's snapshot, and their results are shared by dependency version. Data changes trigger revalidation, checked metric repair, or revocation; feature compilation enforces per-instance temporal bounds. These mechanisms let consumers share validated knowledge and its upkeep along with the savings from reuse (Section~\ref{sec:model}).}
{共享层还提高并维护答案正确性。发布前检查验证提取的定义，再将其提供给其他智能体；从粒度和连接派生的条件在消费查询的快照上检查，检查结果按依赖版本共享。数据变化触发重验证、经检查的指标修复或撤销；特征编译落实逐样本时间边界。这些机制使使用者在获得复用收益的同时，共享经验证的知识及其维护（第~\ref{sec:model} 节）。}

\bi{Our evaluation connects these mechanisms to savings across agents and retraining sessions. On TPC-DS, \PpAgents\ agents use \PpMavraTokSaveNone\% fewer tokens and finish \PpMavraSpeedupNone$\times$ faster than agents without memory; shared memory also uses \PpMavraTokSavePrivate\% fewer tokens than private copies with the same learning mechanisms. RelBench tests reuse across six predictive tasks~\cite{robinson2024relbench}. From the second cutoff onward, token use falls by \RbStackMavraTokSave\% on rel-stack and \RbTrialMavraTokSave\% on rel-trial relative to no memory, with comparable predictive quality. Data-change experiments on TPC-DS, synthetic retail, and TPC-H then examine whether those savings remain useful when previously learned knowledge becomes stale.}
{实验将这些机制与跨智能体、跨重训会话的节省联系起来。在 TPC-DS 上，\PpAgents\ 个智能体相对无记忆减少 \PpMavraTokSaveNone\% 的 token，快 \PpMavraSpeedupNone\ 倍；相对采用相同学习机制的私有记忆，共享记忆还少用 \PpMavraTokSavePrivate\% 的 token。RelBench 进一步检验六项预测任务之间的复用~\cite{robinson2024relbench}：从第二个截点起，在保持相当预测质量的同时，相对无记忆在 rel-stack 和 rel-trial 上分别减少 \RbStackMavraTokSave\% 和 \RbTrialMavraTokSave\% 的 token。TPC-DS、合成零售数据和 TPC-H 上的数据变化实验随后检验，当已学知识过期时，这些节省是否仍能支持有效作答。}

\bi{The contributions are:}{本文的贡献如下：}
\begin{itemize}
\item \bi{A shared memory layer between agents and the database that turns session discoveries into executable metric and feature definitions, reducing repeated exploration across agents and tasks (Sections~\ref{sec:overview} and~\ref{sec:model}).}{在智能体与数据库之间构建共享记忆层，将会话中的发现转化为可执行指标与特征定义，减少跨智能体和任务的重复探索（第~\ref{sec:overview}、\ref{sec:model} 节）。}
\item \bi{A workload analysis, amortization model, and end-to-end evaluation that connect shared knowledge reuse to reductions in LLM calls, tokens, and time (Sections~\ref{sec:background} and~\ref{sec:evaluation}).}{通过负载分析、分摊代价模型和端到端实验，揭示共享知识复用如何减少大模型调用、token 与时间开销（第~\ref{sec:background}、\ref{sec:evaluation} 节）。}
\item \bi{Publication validation, snapshot-bound shared checks, and maintenance mechanisms that improve answer correctness and govern reuse after data changes (Section~\ref{sec:model}).}{通过发布验证、绑定快照的共享检查与维护机制，提高答案正确性，并管理数据变化后的复用（第~\ref{sec:model} 节）。}
\end{itemize}
