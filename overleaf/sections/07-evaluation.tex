\section{\bt{Evaluation}{实验评估}}
\label{sec:evaluation}
\bi{We first measure how shared memory reduces exploration, token consumption, and end-to-end time across agents and sessions. RelBench evaluates reuse across prediction tasks and retraining cutoffs; metric workloads measure sharing across consumers and the cost of learning. We then test whether agents still answer correctly after data changes, examine the limits of validation, and measure the maintenance and optimization costs shared by consumers.}
{我们先测量共享记忆如何减少跨智能体和会话的探索、token 消耗及端到端时间。RelBench 评估跨预测任务与重训截点的复用，指标负载测量跨使用者共享与学习代价。随后检验数据变化后智能体是否仍能正确作答，分析验证的边界，最后测量由使用者共同分摊的维护与优化代价。}
