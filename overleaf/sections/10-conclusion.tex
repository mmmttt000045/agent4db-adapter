\section{\bt{Discussion and Conclusion}{讨论与结论}}
\label{sec:limitations}
\bi{\emph{Future work.} Building on star and snowflake metric definitions and entity-level aggregate features, future work will extend compilation to repeated-role joins and many-to-many bridges, and develop incremental feature maintenance. Richer domain specifications and checks on filter columns and value distributions can further support semantic reconciliation and drift detection.}
{\emph{未来工作。}在星型与雪花型指标定义及实体级聚合特征的基础上，未来工作将把编译扩展到同表多角色连接和多对多桥接表，并探索特征的增量维护。更丰富的领域规约，以及对过滤列和取值分布的检查，将进一步支持业务语义协调与漂移检测。}

\bi{\system\ introduces a database-side shared memory layer that captures, validates, and maintains executable metric and temporally bounded feature definitions across data agents. Binding metric-condition verification to execution snapshots and sharing validation, repair, and equivalent query rewrites reduces redundant exploration and guards against structurally invalid reuse. On six RelBench retraining tasks, executable reuse preserves predictive quality while reducing token consumption by \RbStackMavraTokSave\% on rel-stack and \RbTrialMavraTokSave\% on rel-trial from the second cutoff onward. On TPC-DS, sharing across \PpAgents\ agents cuts token consumption by \PpMavraTokSaveNone\% and raises post-restatement accuracy from \PpNoneChangeAcc\% to \PpMavraChangeAcc\%, turning knowledge learned by one agent into maintained computational assets for many.}
{\system\ 在数据库侧构建共享记忆层，面向多个数据智能体提取、验证并维护可执行指标定义与受时间边界约束的特征定义。将指标条件验证绑定至执行快照，并共享验证、修复与等价查询改写，能够减少重复探索，防范结构失效后的错误复用。在六项 RelBench 重训任务上，可执行知识复用保持了预测质量，从第二个截点起在 rel-stack 和 rel-trial 上分别减少 \RbStackMavraTokSave\% 与 \RbTrialMavraTokSave\% 的 token。在 TPC-DS 上，\PpAgents\ 个智能体共享记忆减少 \PpMavraTokSaveNone\% 的 token，并将数据更正后的正确率从 \PpNoneChangeAcc\% 提高到 \PpMavraChangeAcc\%，使一个智能体学得的知识成为服务多个智能体、持续维护的计算资产。}
