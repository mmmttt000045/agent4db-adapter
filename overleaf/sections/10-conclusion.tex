\section{\bt{Conclusion}{结论}}
\bi{Data agents repeat knowledge rather than queries, and a shared memory that keeps what one agent learned makes later agents more accurate and faster. Such memory describes a database that keeps changing, is produced and consumed by different agents, and can be checked against the database it describes. \system\ therefore keeps it as revisions that carry executable conditions and takes over what consumers cannot do: it publishes only what passes admission, lets a use rely on a revision only on a snapshot on which the revision's conditions hold, and maintains and improves revisions once for all consumers, repairing only with the unique fix that reproduces the producer's answer as of learning time and adopting only equivalent, cheaper rewrites whose premises it then maintains. On libraries learned by three LLMs and on TPC-DS, maintained definitions serve no wrong answer under the covered changes; same-snapshot validation removes answers on condition-violating data under concurrent writers; and end to end, maintained memory keeps agents as accurate as retrieved examples when the data is unchanged and more accurate when it changes, with fewer turns, fewer tokens, shorter tasks, and, after one optimization round, faster definitions. Managed knowledge beyond metric definitions, changes to the meaning of values, undeclared uses, and conflicts between producers mark the next steps.}
{数据智能体重复的是知识而非查询，把一个智能体学到的东西保存下来的共享记忆，能让之后的智能体更准确、更快。这种记忆描述的是一个不断变化的数据库，由不同的智能体生产和使用，又可以对照它所描述的数据库来检查。因此，\system\ 把它保存为带有可执行条件的修订，并承担使用者做不到的部分：只发布通过准入的内容；只允许一次使用在修订条件成立的快照上依赖该修订；为所有使用者一次性地维护和改进修订，只用按学习时刻复现生产者答案的唯一修复来修复，只采纳等价且更省、并且其前提随后受到维护的改写。在 3 个大模型学到的定义库和 TPC-DS 上，维护后的定义在条件覆盖的变化下不给出错误答案；同快照验证在并发写入下消除了在违反条件的数据上作答；端到端实验中，维护后的记忆在数据不变时让智能体与检索到的示例一样准确，在数据变化时更准确，而且轮数更少、token 更少、任务更短，一轮优化之后定义本身也更快。指标定义之外的受管理知识、取值含义的变化、未声明的使用以及生产者之间的冲突，是下一步的方向。}
