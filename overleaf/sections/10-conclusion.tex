\section{\bt{Discussion and Conclusion}{讨论与结论}}
\label{sec:limitations}
\bi{\emph{Scope.} \system\ shares metric definitions over star and snowflake schemas with a date dimension or a date column; a table joined twice in different roles and many-to-many bridges are outside the implementation. Its guarantee covers declared uses and the conditions of Section~\ref{sec:sufficiency}: changes to the values themselves, a valid but wrong date key, and undeclared SQL lie outside it, and an ambiguous repair goes to a human with its candidates. Learning sessions pass through one set of publication checks; reconciling the meanings that different teams give one name is left to people.}
{\emph{适用范围。}\system\ 共享以日期维度或日期列给出日期的星型与雪花型模式上的指标定义；同一张表以不同角色连接两次、多对多的桥接表不在实现范围内。它的保证覆盖声明了版本的使用和第~\ref{sec:sufficiency} 节的条件：取值本身的变化、合法但错误的日期键以及未声明的 SQL 不在保证范围内，有歧义的修复带着候选交给人确认。学习会话经过同一组发布前检查；不同团队对同一名称给出的含义由人来调和。}

\bi{Data agents spend their time and tokens rediscovering what other agents already found, and memory kept per agent does not change that. \system\ moves the memory to the database and shares it: one agent explores, every agent reuses, and the checks, repairs, and optimizations that keep the shared knowledge correct and fast are done once for all of them. Across a population of agents this saves most of the tokens and agent time that exploring alone or remembering alone would spend, and it keeps the saved answers correct when the data changes.}
{数据智能体把时间和 token 花在重新发现其他智能体早已发现的东西上，而按智能体保存的记忆改变不了这一点。\system\ 把记忆移到数据库一侧并加以共享：一个智能体探索，所有智能体复用；让共享知识保持正确、保持高效的检查、修复和优化，也为所有智能体只做一次。在一群智能体上，它省下了独自探索或各自记忆所要花费的大部分 token 和智能体时间，并在数据变化时让这些省下来的答案保持正确。}
