\section{\bt{Discussion and Conclusion}{讨论与结论}}
\label{sec:limitations}
\bi{\system\ guarantees that a declared use runs on data that satisfies its revision's conditions, which cover grain, join cardinality and completeness, and the date join; the learning record supplies the meaning. They apply to star and snowflake schemas with a date dimension or a date column; a table joined twice in different roles and many-to-many bridges are outside the implementation. Changes to the values themselves (the unit change), a valid but wrong date key, and undeclared SQL lie outside the guarantee, and an ambiguous repair goes to a human with its candidates. One built-in learning agent publishes through one set of checks for many consumers; reconciling the meanings that different producers give one name is left to people.}
{\system\ 保证声明了版本的使用在满足该版本条件的数据上执行，条件覆盖粒度、连接基数与连接完整性以及日期连接；学习记录提供含义。条件适用于以日期维度或日期列给出日期的星型与雪花型模式；同一张表以不同角色连接两次、多对多的桥接表不在实现范围内。取值本身的变化（单位变化）、合法但错误的日期键以及未声明的 SQL 不在保证范围内；有歧义的修复带着候选交给人确认。一个内置学习智能体经由同一组发布前检查为众多使用者产生候选；不同生产者对同一名称给出的含义由人来调和。}

\bi{Data agents repeat knowledge rather than queries. \system\ keeps that knowledge as revisions whose executable conditions are checked against the database they describe: it publishes only what passes the publication checks, lets a query use a revision only where its conditions hold, and maintains and optimizes revisions once for all consumers. The memory makes agents as accurate as retrieved examples and faster than exploring alone on unchanged data, and more accurate when the data changes.}
{数据智能体重复的是知识而非查询。\system\ 把这些知识保存为版本，其可执行条件对照所描述的数据库检查：只发布通过发布前检查的内容；只允许查询在版本条件成立的快照上使用该版本；为所有使用者一次性地维护和优化版本。这一记忆在数据不变时让智能体与检索到的示例一样准确、比独自探索更快，在数据变化时更准确。}
