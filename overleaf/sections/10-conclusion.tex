\section{\bt{Conclusion}{结论}}
\bi{Data agents repeat knowledge rather than queries, and a shared memory that keeps what one agent learned makes later agents more accurate and faster. Because that memory describes a changing database, is produced and consumed by different agents, and can be checked against the database it describes, \system\ keeps it as revisions with executable conditions and takes over what no consumer should carry alone: it publishes only what passes admission, lets a use rely on a revision only on a snapshot on which its conditions hold, and maintains and improves revisions once for all consumers. Maintained definitions serve no wrong answer under the covered changes, same-snapshot validation removes answers on condition-violating data, and end to end the memory keeps agents as accurate as retrieved examples on unchanged data and more accurate when the data changes, while making their tasks faster.}
{数据智能体重复的是知识而非查询，把一个智能体学到的东西保存下来的共享记忆，能让之后的智能体更准确、更快。由于这种记忆描述的是一个不断变化的数据库，由不同的智能体生产和使用，又可以对照它所描述的数据库来检查，\system\ 把它保存为带有可执行条件的修订，并承担不应由每个使用者各自承担的部分：只发布通过准入的内容；只允许一次使用在修订条件成立的快照上依赖该修订；为所有使用者一次性地维护和改进修订。维护后的定义在条件覆盖的变化下不给出错误答案，同快照验证消除了在违反条件的数据上作答；端到端实验中，记忆在数据不变时让智能体与检索到的示例一样准确，在数据变化时更准确，同时让任务更快。}
