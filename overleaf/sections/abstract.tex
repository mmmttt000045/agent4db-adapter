\begin{abstract}
\bi{Data agents repeatedly explore the same database across tasks and sessions, spending LLM calls on knowledge that previous agents have already discovered. We present \system, a shared memory layer between data agents and the database that reduces exploration, token consumption, and end-to-end time. The layer extracts executable metric and feature definitions from successful sessions, shares them across agents, and compiles them for new questions and prediction instances. Learning, validation, and optimization costs are amortized across consumers. On a TPC-DS workload with \PpAgents\ agents, \system\ reduces token consumption by \PpMavraTokSaveNone\% and achieves a \PpMavraSpeedupNone$\times$ end-to-end speedup relative to no memory, while using \PpMavraTokSavePrivate\% fewer tokens than private memory. On six RelBench retraining tasks, token use from the second cutoff onward falls by \RbStackMavraTokSave\% on rel-stack and \RbTrialMavraTokSave\% on rel-trial relative to no memory, with comparable predictive quality. The layer also improves and maintains correctness through publication checks, snapshot-bound condition validation, and shared maintenance. TPC-DS accuracy increases from \PpNoneAcc\% to \PpMavraAcc\% initially and reaches \PpMavraChangeAcc\% after a data restatement, compared with \PpNoneChangeAcc\% without memory.}
{数据智能体在不同任务和会话中反复探索同一数据库，花费大模型调用重新发现此前智能体已经获得的知识。本文提出 \system，一个位于数据智能体与数据库之间的共享记忆层，用于减少探索、token 消耗和端到端时间。共享层从成功会话中提取可执行的指标与特征定义，在智能体之间共享，并为新的问题和预测样本编译查询；学习、验证与优化开销由多个使用者分摊。在 \PpAgents\ 个智能体的 TPC-DS 负载上，\system\ 相对无记忆减少 \PpMavraTokSaveNone\% 的 token，获得 \PpMavraSpeedupNone\ 倍端到端加速，相对私有记忆减少 \PpMavraTokSavePrivate\% 的 token。在六项 RelBench 重训任务上，从第二个截点起，相对无记忆在 rel-stack 和 rel-trial 上分别减少 \RbStackMavraTokSave\% 与 \RbTrialMavraTokSave\% 的 token，同时保持相当的预测质量。共享层还通过发布检查、绑定快照的条件验证及统一维护，提高并维护正确性：TPC-DS 初始正确率从 \PpNoneAcc\% 提高到 \PpMavraAcc\%，数据更正后达到 \PpMavraChangeAcc\%，无记忆为 \PpNoneChangeAcc\%。}
\end{abstract}
