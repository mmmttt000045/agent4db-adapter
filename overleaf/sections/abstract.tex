\begin{abstract}
\bi{Data agents repeatedly inspect schemas, probe values, and validate joins before generating analytical queries or predictive features over the same database. Existing agent memories retain textual descriptions that agents must still translate into SQL, while underlying data updates can silently invalidate reused queries. We present \system, a database-side memory layer that shares verified, executable metric and feature definitions across agents. The system extracts structured definitions from successful sessions, validates candidates before publication, and compiles feature definitions with per-instance temporal bounds that prevent future-data leakage. For metric queries, executable conditions derived from grain and joins bind reuse to the execution snapshot; validation results are shared, and maintenance and query optimization are amortized across consumers. Under periodic retraining on RelBench's \texttt{rel-stack} and \texttt{rel-trial} databases, \system\ reduces token consumption from the second cutoff onward by \RbStackMavraTokSave\% and \RbTrialMavraTokSave\%, respectively, relative to memoryless agents, and by \RbStackMavraVsBest\% on both databases relative to the most token-efficient agent-memory baseline, while maintaining comparable predictive quality across all six tasks. On TPC-DS, \PpAgents\ agents using \system\ consume \PpMavraTokSaveNone\% fewer tokens than memoryless agents; after a data restatement, they achieve \PpMavraChangeAcc\% accuracy compared with \PpNoneChangeAcc\% for memoryless agents.}
{数据智能体在同一数据库上生成分析查询或预测特征之前，会反复检查模式、探查取值并验证连接。现有智能体记忆仅保留文字描述，智能体仍须将其转化为 SQL，而底层数据更新又可能使复用的查询悄然失效。本文提出 \system，一个在数据库侧向多个智能体共享经验证的可执行指标与特征定义的记忆层。系统从成功会话中提取结构化定义，在发布前验证候选定义，并将特征定义编译为带逐样本时间边界的 SQL 以防止未来数据泄漏。对于指标查询，由粒度与连接关系导出的可执行条件将定义复用绑定至查询执行快照；验证结果可被共享，维护与查询优化的开销由所有使用者共同分摊。在 RelBench 的 \texttt{rel-stack} 与 \texttt{rel-trial} 数据库的定期重训任务中，从第二个截点起，\system\ 相对无记忆智能体分别减少 \RbStackMavraTokSave\% 与 \RbTrialMavraTokSave\% 的 token，相对各库中 token 用量最低的智能体记忆基线均减少 \RbStackMavraVsBest\%，同时在全部六项任务上保持相当的预测质量。在 TPC-DS 上，\PpAgents\ 个使用 \system\ 的智能体比无记忆智能体少消耗 \PpMavraTokSaveNone\% 的 token；在数据更正后，其正确率为 \PpMavraChangeAcc\%，而无记忆智能体为 \PpNoneChangeAcc\%。}
\end{abstract}
