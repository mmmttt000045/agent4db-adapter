\bi{\emph{After a restatement (Q4).} Following the population study, a restatement corrects store sales while retaining old amounts as non-current rows. Each of the \PpAgents\ agents returns with four affected questions, matched across methods within each of five runs. With each definition repaired once, \system\ answers \PpMavraChangeAcc\% correctly at \PpMavraChangeTokK\,k tokens per question. Example retrieval answers \PpTrajChangeAcc\% at \PpTrajChangeTokK\,k; no memory answers \PpNoneChangeAcc\% at \PpNoneChangeTokK\,k. Each accuracy uses 320 post-restatement sessions. Example retrieval preserves low reuse cost, but its stored SQL lacks maintenance when the original data assumptions change. The contrast supports maintaining reusable computation beyond retaining successful examples.}
{\emph{一次更正之后（Q4）。}群体实验后，一次更正修改门店销售并将旧金额保留为非当前行。\PpAgents\ 个智能体各回来回答四道受影响的题，五轮运行中每轮各方法的题目匹配。每个定义只修复一次后，\system\ 每题用 \PpMavraChangeTokK\,k token、答对 \PpMavraChangeAcc\%；示例检索每题用 \PpTrajChangeTokK\,k、答对 \PpTrajChangeAcc\%；无记忆每题用 \PpNoneChangeTokK\,k、答对 \PpNoneChangeAcc\%。各正确率的分母均为 320 个更正后会话。示例检索维持了较低的复用开销，但原查询的数据前提变化后，其存储的 SQL 缺少维护。这一对照支持在保留成功示例之外，持续维护可复用的计算。}

\bi{\emph{Eleven changes on two schemas.} The end-to-end study repeats affected questions after four non-breaking updates, five targeted structural changes (status rows, restatements, duplicate loads, SCD Type 2, and date-key changes), and two changes outside the conditions (Figure~\ref{fig:twoschemas}). On the targeted changes, \system\ answers \DsCondModeled\% correctly on the synthetic data and \GeCondModeled\% on TPC-H. The no-memory control answers \DsNoShareModeled\% and \GeNoShareModeled\%, respectively.}
{\emph{两种模式上的十一种变化。}端到端研究在四种正常更新、五种目标结构变化（状态流水、更正、重复加载、缓慢变化维类型 2 和日期键变化），以及两种条件范围外变化后重问受影响的题（图~\ref{fig:twoschemas}）。在目标结构变化下，\system\ 在合成数据上答对 \DsCondModeled\%，在 TPC-H 上答对 \GeCondModeled\%；无记忆参照分别答对 \DsNoShareModeled\% 和 \GeNoShareModeled\%。}

\bi{\emph{Preventing invalid reuse.} Table~\ref{tab:replay-safety} separates correct service, incorrect service, and refusal across TPC-DS, TPC-H, SSB, and BIRD financial. In five targeted structural scenarios, maintenance blocks \the\numexpr\RsStructuralRefused-\RsStructuralUnneeded\relax\ uses whose original SQL would be incorrect; \RsStructuralWrong\ incorrect results are served, and \RsStructuralUnneeded\ otherwise-correct uses are conservatively refused. All three structural errors arise from one TPC-H Q12 definition: a null auxiliary filter column drops rows despite passing date coverage. The unit/backup scenarios additionally return \RsOutsideWrong/\RsOutsideN\ incorrect results and \RsOutsideRefused\ refusals, illustrating the need for unit and source-of-record semantics.}
{\emph{阻止失效复用。}表~\ref{tab:replay-safety} 在 TPC-DS、TPC-H、SSB 与 BIRD financial 上区分正确服务、错误服务与拒绝。五类目标结构变化中，维护阻止 \the\numexpr\RsStructuralRefused-\RsStructuralUnneeded\relax\ 次原 SQL 会出错的使用；错误服务 \RsStructuralWrong\ 次，另保守拒绝 \RsStructuralUnneeded\ 次原本正确的使用。三次结构错误均来自同一个 TPC-H Q12 定义：辅助过滤列为空使行被排除，而日期覆盖检查仍通过。单位／备份场景另有 \RsOutsideWrong/\RsOutsideN\ 次错误服务与 \RsOutsideRefused\ 次拒绝，表明需要量纲和权威来源语义。}
