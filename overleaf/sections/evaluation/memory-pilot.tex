\subsection{\bt{Program and definition access: a development pilot}{程序与定义访问：开发预实验}}
\label{sec:memory-pilot}
\input{figures/memory-access-pilot}
\bi{\emph{Controls.} Figure~\ref{fig:memory-access-pilot} varies program and definition access in a $2\times2$ pilot. One audited user-badge program supplies seven definitions admitted from twelve fresh candidates. Targets are same-cutoff user-engagement and next-cutoff user-badge. Each cell has identical samples and base tools, low-effort official-API calls, a 12-call/three-validation budget, optional memory use, and no target writeback. Training/validation samples contain 10,000/2,000 seeds; temporal audits use up to 5,000 training seeds. Test labels are neither read nor scored.}
{\emph{对照。}图~\ref{fig:memory-access-pilot}以$2\times2$预实验改变程序与定义访问。一个经审计的user-badge程序重新产生十二个候选，其中七个定义获准发布；目标为同截点user-engagement及下一截点user-badge。每格共用样本与基础工具、低强度官方API、12次调用／3次验证预算，记忆按需使用且目标不写回。训练／验证为10,000／2,000种子，时间审计最多5,000训练种子，不读取或评分测试标签。}
\bi{\emph{Findings and scope.} Six cells yield valid SQL; cross-task N/B exhaust the budget without a solution. At the later cutoff, N/P/D/B reach AUCs \MeANoneAUC/\MeAProgramAUC/\MeADefinitionAUC/\MeABothAUC. B's \MeABothOnlineK\,k online tokens are below N's \MeANoneOnlineK\,k, but become \MeABothTotalK\,k with source costs amortized over two targets. No cell explicitly composes a subset or validates returned SQL verbatim; B retrieves only definitions at the later cutoff. Rewrites may still use retrieved knowledge. One run per cell, unequal source feature content, and agent-managed seed-key adaptation prevent a representation-effect or test non-inferiority claim. Six interface-interrupted cells are rerun after fixes; completed controls and all costs are retained. Content-matched repetitions and uniform query deadlines are required for confirmation.}
{\emph{结果与范围。}六格产出有效SQL，跨任务N/B用完预算仍无方案。后续截点N/P/D/B的AUC为\MeANoneAUC/\MeAProgramAUC/\MeADefinitionAUC/\MeABothAUC。B的\MeABothOnlineK\,k在线token低于N的\MeANoneOnlineK\,k，但计入按两个目标分摊的源成本后为\MeABothTotalK\,k。没有显式组合子集或原样验证返回SQL的单元；后续截点B仅检索定义，改写仍可能参考检索知识。每格一次、源特征内容不等和智能体自行适配种子键，使结果不能归因于表示形式或证明测试非劣性。接口中断的六个记忆格修复后补跑，已完成对照及所有成本保留。确认性研究需要内容匹配的重复及统一查询时限。}
