\bi{\emph{Protocol (Q1).} \PpAgents\ agents arrive sequentially at the TPC-DS database. Each draws seven questions from the 35-question workload in Section~\ref{sec:metric-setup}; all methods receive the same draw within a run. Memory starts empty. A correctly answered learning question triggers extraction and publication unless it already reused a definition. Memoryless agents retain no state across questions. The single-agent baseline uses the same learning, validation, and maintenance mechanisms as \system, but restricts each agent to its own definitions, table descriptions, and join paths. Four methods---no memory, single-agent memory, example retrieval, and \system---each run \PpRuns\ times: $4\times\PpAgents\times7\times\PpRuns=2{,}240$ initial sessions and $4\times\PpAgents\times4\times\PpRuns=1{,}280$ post-restatement sessions (Section~\ref{sec:changes-eval}), totaling \PpSessions. Initial-stage results below and post-restatement results use their respective denominators. Session tokens include any extraction they trigger.}
{\emph{设置（Q1）。}\PpAgents\ 个智能体依次到达 TPC-DS 数据库，每个从第~\ref{sec:metric-setup} 节的 35 道题中抽取 7 道，同一次运行中各方法抽到的题相同。记忆初始为空；答对学习题且尚未复用定义的会话触发提取与发布。无记忆智能体不跨题保留状态。单智能体基线使用与 \system\ 相同的学习、验证和维护机制，但每个智能体只能使用自己学到的定义、表描述及连接路径。无记忆、单智能体记忆、示例检索与 \system\ 四种方法各运行 \PpRuns\ 次：初始阶段 $4\times\PpAgents\times7\times\PpRuns=2{,}240$ 个会话，更正后 $4\times\PpAgents\times4\times\PpRuns=1{,}280$ 个会话（第~\ref{sec:changes-eval} 节），合计 \PpSessions\ 个。下文初始阶段结果与更正后结果分别使用对应阶段的分母；会话 token 包括其触发的提取。}

\bi{\emph{What sharing saves.} Figure~\ref{fig:population} shows cumulative cost. Over \PpAgents\ agents, \system\ uses \PpMavraTotalTokM\,M tokens, \PpMavraTokSaveNone\% fewer than no memory (\PpNoneTotalTokM\,M; savings \PpMavraTokSaveNoneMin--\PpMavraTokSaveNoneMax\% per run), finishes \PpMavraSpeedupNone$\times$ faster, and answers \PpMavraAcc\% correctly versus \PpNoneAcc\%. Token savings and speedups grow from \PpMavraTokSaveNoneNFour\% and \PpMavraSpeedupNoneNFour$\times$ after four agents to \PpMavraTokSaveNoneNEight\% and \PpMavraSpeedupNoneNEight$\times$ after eight. As Section~\ref{sec:alternatives} predicts, token savings approach $1-c_r/c_e=\PpMavraAsymTokSaveNone\%$ as reuse grows. Early sessions perform \PpMavraLearns\ extractions per run for five metrics; \PpMavraReused\% of all questions reuse a definition. Table~\ref{tab:popcost} shows why: reuse replaces schema, value, and join probes, reducing LLM calls from \PpNoneLateSteps\ to \PpMavraLateSteps\ and tool calls from \PpNoneLateTools\ to \PpMavraLateTools\ per question. Avoiding calls with growing contexts cuts tokens \PpMavraLateTokXNone$\times$ and time \PpMavraLateSpeedupNone$\times$; database time falls from \PpNoneLateDbS\ to \PpMavraLateDbS\,s. In a separate \SlSessions-session study, LLM calls account for \SlWarmLLMMin--\SlWarmLLMMax\% of agent time when using shared memory.}
{\emph{共享省下了什么。}图~\ref{fig:population} 展示累计代价。\PpAgents\ 个智能体共用 \PpMavraTotalTokM\,M token，比无记忆（\PpNoneTotalTokM\,M）少 \PpMavraTokSaveNone\%（每次运行省 \PpMavraTokSaveNoneMin--\PpMavraTokSaveNoneMax\%），快 \PpMavraSpeedupNone\ 倍，正确率为 \PpMavraAcc\%，无记忆为 \PpNoneAcc\%。token 节省与加速从 4 个智能体后的 \PpMavraTokSaveNoneNFour\% 与 \PpMavraSpeedupNoneNFour\ 倍，增至 8 个后的 \PpMavraTokSaveNoneNEight\% 与 \PpMavraSpeedupNoneNEight\ 倍。如第~\ref{sec:alternatives} 节所预测，复用增加时 token 节省趋近 $1-c_r/c_e=\PpMavraAsymTokSaveNone\%$。早期会话每次运行为五个指标提取 \PpMavraLearns\ 次；全部问题中 \PpMavraReused\% 复用定义。表~\ref{tab:popcost} 说明原因：复用替代模式、取值与连接探查，使每题大模型调用从 \PpNoneLateSteps\ 降至 \PpMavraLateSteps\ 次、工具调用从 \PpNoneLateTools\ 降至 \PpMavraLateTools\ 次。省去上下文不断增长的调用，使 token 少 \PpMavraLateTokXNone\ 倍、时间快 \PpMavraLateSpeedupNone\ 倍；数据库时间从 \PpNoneLateDbS\ 降至 \PpMavraLateDbS\ 秒。另一项 \SlSessions\ 会话研究中，大模型调用占共享记忆使用会话耗时的 \SlWarmLLMMin--\SlWarmLLMMax\%。}


\bi{\emph{Why memory must be shared.} Private memory extracts \PpPrivateLearns\ times per run but reuses on only \PpPrivateReused\% of questions: individual agents seldom revisit learned metrics. It spends \PpPrivateTotalTokM\,M tokens over \PpAgents\ agents, including \PpPrivateLateTokK\,k per late question; \system\ uses \PpMavraTokSavePrivate\% fewer tokens and runs \PpMavraSpeedupPrivate$\times$ faster.}
{\emph{为什么记忆必须共享。}私有记忆每次运行提取 \PpPrivateLearns\ 次，但仅在 \PpPrivateReused\% 的问题上复用，因为单个智能体很少重问已学指标。\PpAgents\ 个智能体共花 \PpPrivateTotalTokM\,M token，后来的智能体每题仍花 \PpPrivateLateTokK\,k；\system\ 少用 \PpMavraTokSavePrivate\% 的 token，快 \PpMavraSpeedupPrivate\ 倍。}
