\subsection{\bt{Amortizing Exploration Across Agent Populations (Q1)}{跨智能体群体分摊探索代价（Q1）}}
\label{sec:population-eval}
\bi{Shared memory amortizes metric discovery across the agent population. Over \PpAgents\ agents, \system\ cuts cumulative token consumption by \PpMavraTokSaveNone\% and achieves a \PpMavraSpeedupNone$\times$ speedup in total agent time relative to no memory (Figure~\ref{fig:population}).}

\bi{\emph{Protocol.} \PpAgents\ agents arrive sequentially at the TPC-DS database. Each draws seven questions from the 35-question workload in Section~\ref{sec:metric-setup}; all methods receive the same draw within a run. Memory starts empty. A correctly answered learning question triggers extraction and publication unless it already reused a definition. Memoryless agents retain no state across questions. The single-agent baseline uses the same learning, validation, and maintenance mechanisms as \system, but restricts each agent to its own definitions, table descriptions, and join paths. Evaluating four methods---no memory, single-agent memory, trajectory retrieval, and \system---across \PpRuns\ independent runs yields \PpSessions\ sessions in total: 2,240 initial and 1,280 post-restatement (Section~\ref{sec:changes-eval}). Initial-stage results below and post-restatement results use their respective denominators. Session tokens include any extraction they trigger.}
{\emph{设置。}\PpAgents\ 个智能体依次到达 TPC-DS 数据库，每个从第~\ref{sec:metric-setup} 节的 35 道题中抽取 7 道，同一次运行中各方法抽到的题相同。记忆初始为空；答对学习题且尚未复用定义的会话触发提取与发布。无记忆智能体不跨题保留状态。单智能体基线使用与 \system\ 相同的学习、验证和维护机制，但每个智能体只能使用自己学到的定义、表描述及连接路径。无记忆、单智能体记忆、轨迹检索与 \system\ 四种方法各独立运行 \PpRuns\ 次，共得到 \PpSessions\ 个会话：初始阶段 2,240 个，更正后 1,280 个（第~\ref{sec:changes-eval} 节）。下文初始阶段结果与更正后结果分别使用对应阶段的分母；会话 token 包括其触发的提取。}

\bi{\emph{How savings accumulate.} Figure~\ref{fig:population} shows the learning cost being spread over successive agents. Token savings rise from \PpMavraTokSaveNoneNFour\% after four agents to \PpMavraTokSaveNoneNEight\% after eight, while speedup rises from \PpMavraSpeedupNoneNFour$\times$ to \PpMavraSpeedupNoneNEight$\times$. Over the full population, token use is \PpMavraTotalTokM\,M with \system\ and \PpNoneTotalTokM\,M without memory; savings range from \PpMavraTokSaveNoneMin\% to \PpMavraTokSaveNoneMax\% across runs. Accuracy also rises from \PpNoneAcc\% to \PpMavraAcc\%.}
{\emph{节省如何积累。}图~\ref{fig:population} 展示学习代价如何由陆续到来的智能体分摊。四个智能体后的 token 节省为 \PpMavraTokSaveNoneNFour\%，到八个时增至 \PpMavraTokSaveNoneNEight\%；加速也从 \PpMavraSpeedupNoneNFour\ 倍增至 \PpMavraSpeedupNoneNEight\ 倍。整个群体使用 \system\ 共消耗 \PpMavraTotalTokM\,M token，无记忆则为 \PpNoneTotalTokM\,M；各次运行节省 \PpMavraTokSaveNoneMin\% 至 \PpMavraTokSaveNoneMax\%。正确率同时从 \PpNoneAcc\% 提高到 \PpMavraAcc\%。}

\bi{The later questions in Table~\ref{tab:popcost} reveal the mechanism. Reusing definitions replaces schema, value, and join probes, reducing LLM calls from \PpNoneLateSteps\ to \PpMavraLateSteps\ and tool calls from \PpNoneLateTools\ to \PpMavraLateTools\ per question. Avoiding those calls also avoids their growing contexts, explaining the table's token and time reductions. Early sessions perform \PpMavraLearns\ extractions per run for five metrics, and \PpMavraReused\% of all questions reuse a definition. As reuse grows, token savings approach $1-c_r/c_e=\PpMavraAsymTokSaveNone\%$, as predicted in Section~\ref{sec:alternatives}. A separate \SlSessions-session study finds that LLM calls still account for \SlWarmLLMMin--\SlWarmLLMMax\% of agent time with shared memory.}
{表~\ref{tab:popcost} 中的后续问题揭示了节省的来源。定义复用替代模式、取值和连接探查，使每题大模型调用从 \PpNoneLateSteps\ 降至 \PpMavraLateSteps\ 次，工具调用从 \PpNoneLateTools\ 降至 \PpMavraLateTools\ 次。省去调用也省去了其不断增长的上下文，因此获得表中所示的 token 和时间收益。早期会话每次运行为五个指标完成 \PpMavraLearns\ 次提取，全部问题中有 \PpMavraReused\% 复用定义。复用增加时，token 节省趋近第~\ref{sec:alternatives} 节预测的 $1-c_r/c_e=\PpMavraAsymTokSaveNone\%$。另一项 \SlSessions\ 会话研究表明，即使使用共享记忆，大模型调用仍占智能体耗时的 \SlWarmLLMMin--\SlWarmLLMMax\%。}


\bi{\emph{Why memory must be shared.} Private memory extracts \PpPrivateLearns\ times per run but reuses on only \PpPrivateReused\% of questions: individual agents seldom revisit learned metrics. It spends \PpPrivateTotalTokM\,M tokens over \PpAgents\ agents, including \PpPrivateLateTokK\,k per late question; \system\ uses \PpMavraTokSavePrivate\% fewer tokens and runs \PpMavraSpeedupPrivate$\times$ faster.}
{\emph{为什么记忆必须共享。}私有记忆每次运行提取 \PpPrivateLearns\ 次，但仅在 \PpPrivateReused\% 的问题上复用，因为单个智能体很少重问已学指标。\PpAgents\ 个智能体共花 \PpPrivateTotalTokM\,M token，后来的智能体每题仍花 \PpPrivateLateTokK\,k；\system\ 少用 \PpMavraTokSavePrivate\% 的 token，快 \PpMavraSpeedupPrivate\ 倍。}
