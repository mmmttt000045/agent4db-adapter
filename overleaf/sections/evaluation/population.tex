\subsection{\bt{Sharing across a population of agents}{在一群智能体之间共享}}
\label{sec:population-eval}
\input{tables/population-cost}
\bi{\emph{Protocol (Q1).} \PpAgents\ sequential TPC-DS agents each draw seven of 35 metric questions, matched across methods within a run. Memory starts empty; a correct learning answer triggers extraction unless it reused a definition. Definitions, table descriptions, verified joins, and check/result caches are per-question without memory, per-agent with private \system\ memory, and global with shared \system\ memory. These three scope configurations share learning and maintenance mechanisms. Five runs produce 1,680 initial sessions and 960 post-restatement sessions (four questions per agent); their denominators remain separate. Tokens include extraction. In the other held-out/change studies, even memoryless agents share base metadata and caches to isolate definitions and maintenance.}
{\emph{协议（Q1）。}\PpAgents{}个TPC-DS智能体依次到达，各从35题中抽7题，同轮方法间抽题一致。记忆初始为空，答对学习题且未复用定义时触发提炼。定义、表描述、验证连接及检查／结果缓存，在无记忆时按题保留、私有\system{}按智能体保留、共享\system{}全局保留；三种作用域共用学习维护机制。五轮产生1,680个初始会话和960个更正后会话（每智能体四题），两阶段分母分开，token包括提炼。其他留出／变化研究中，无记忆智能体也共享基础元数据及缓存，以分离定义维护的收益。}
\bi{\emph{Scope results.} Shared memory uses \PpMavraTotalTokM\,M tokens, \PpMavraTokSaveNone\% below no memory, with \PpMavraAcc\% versus \PpNoneAcc\% accuracy. It performs \PpMavraLearns\ extraction operations per run and reuses definitions in \PpMavraReused\% of questions. Private memory performs \PpPrivateLearns\ extraction operations but reuses definitions in only \PpPrivateReused\% of questions, spending \PpPrivateTotalTokM\,M tokens. Shared memory saves \PpMavraTokSavePrivate\% tokens and runs \PpMavraSpeedupPrivate$\times$ faster; Table~\ref{tab:popcost} reports late-session behavior.}
{\emph{作用域结果。}共享记忆使用\PpMavraTotalTokM\,M token，比无记忆少\PpMavraTokSaveNone\%，正确率为\PpMavraAcc\%对\PpNoneAcc\%。每轮执行\PpMavraLearns{}次提取，\PpMavraReused\%的题复用定义。私有记忆执行\PpPrivateLearns{}次提取，却仅在\PpPrivateReused\%的题上复用，消耗\PpPrivateTotalTokM\,M token；共享记忆少用\PpMavraTokSavePrivate\% token、快\PpMavraSpeedupPrivate{}倍。表~\ref{tab:popcost}报告后期行为。}
\bi{\emph{Publication fidelity.} Across \PubAllJudged\ verified metric sessions, replay rejects \PubReplayRefused\ erroneous candidates and calculation checks reject \PubChainRefused\ more. Dropping an electronics filter, for example, changes \PubExAnswer\ to \PubExCanon\ (\PubExRatio-fold error). This tests publication fidelity separately from feature reuse.}
{\emph{发布保真性。}在\PubAllJudged{}个答案已核实的指标会话中，重放拒绝\PubReplayRefused{}个错误候选，算式检查另拒绝\PubChainRefused{}个。例如丢失电子品类过滤，将\PubExAnswer{}变成\PubExCanon{}，误差\PubExRatio{}倍。这与特征复用分别检验不同问题。}
