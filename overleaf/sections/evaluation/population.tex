\subsection{\bt{Sharing across a population of agents}{在一群智能体之间共享}}
\label{sec:population-eval}
\input{figures/population}
\bi{\emph{Protocol (Q1).} \PpAgents\ agents arrive one after another at the TPC-DS database, and each asks seven questions drawn at random from the 35 of its workload, so most agents meet a metric only once or twice. Learning questions come with their business definition and the others with the metric name only; within a run every method gets the same draw. The memory starts empty and learns from use: when a session answers a learning question correctly without reusing a definition, \system\ extracts a candidate and publishes it after the publication checks, and example retrieval stores the session. Without memory, an agent starts every question from scratch, including the table profiles and join paths it looks up. \emph{Single-agent memory} runs exactly \system's learning, checks, and maintenance, but each agent sees only the definitions and schema knowledge it learned itself, as in current agent memory systems. Agents look up memory at most three times per question. After the \PpAgents\ agents, a restatement changes store sales, and every agent returns with four questions about the metrics that read them. Each method runs \PpRuns\ times; a session's tokens include the extraction it triggered, and agent time is the time agents spend answering.}
{\emph{设置（Q1）。}\PpAgents\ 个智能体依次来到 TPC-DS 数据库，每个从其负载的 35 道题中随机抽 7 道作答，因此大多数智能体只遇到某个指标一两次。学习题给出业务定义，其余题只给指标名；同一次运行中各方法抽到的题相同。记忆从空开始、边用边学：若一个会话答对了学习题、且没有复用已有定义，\system\ 提取候选并在发布前检查之后发布，示例检索则保存该会话。没有记忆的智能体每道题都从头开始，查过的表描述和关联路径也不保留。\emph{单智能体记忆}完全照搬 \system\ 的学习、检查与维护，但每个智能体只看得到自己学到的定义和表结构知识，与现有智能体记忆系统相同。每道题最多查找三次记忆。\PpAgents\ 个智能体之后，一次更正修改门店销售，每个智能体再回来回答 4 道读到它的指标的题。每种方法运行 \PpRuns\ 次；会话的 token 包括它触发的提取，智能体时间是智能体作答所花的时间。}

\bi{\emph{What sharing saves.} Figure~\ref{fig:population} shows the total cost as agents arrive. Over \PpAgents\ agents, \system\ spends \PpMavraTotalTokM\,M tokens, \PpMavraTokSaveNone\% fewer than agents without memory (\PpNoneTotalTokM\,M) and \PpMavraTokSavePrivate\% fewer than single-agent memory (\PpPrivateTotalTokM\,M), and its agents finish \PpMavraSpeedupNone$\times$ and \PpMavraSpeedupPrivate$\times$ faster, while answering \PpMavraAcc\% of the questions correctly against \PpNoneAcc\% and \PpPrivateAcc\%. The difference is where exploration happens. In \system\ the first sessions that meet a metric explore and publish, \PpMavraLearns\ extractions per run for the five metrics, and from then on agents reuse: \PpMavraReused\% of all questions run a shared definition. Once the metrics are learned, each agent of the second half answers a question with \PpMavraLateTokK\,k tokens in \PpMavraLateS\,s, \PpMavraLateTokXNone$\times$ fewer tokens and \PpMavraLateSpeedupNone$\times$ faster than without memory (\PpNoneLateTokK\,k tokens, \PpNoneLateS\,s). Single-agent memory extracts \PpPrivateLearns\ times per run, yet reuses on only \PpPrivateReused\% of the questions, because an agent that learned a metric seldom asks about it again: every agent pays for learning, and few get the reuse. Its late agents still spend \PpPrivateLateTokK\,k tokens and \PpPrivateLateS\,s per question.}
{\emph{共享省下了什么。}图~\ref{fig:population} 给出智能体陆续到来时的累计代价。\PpAgents\ 个智能体下来，\system\ 共用 \PpMavraTotalTokM\,M token，比无记忆的智能体（\PpNoneTotalTokM\,M）少 \PpMavraTokSaveNone\%，比单智能体记忆（\PpPrivateTotalTokM\,M）少 \PpMavraTokSavePrivate\%；其智能体分别快 \PpMavraSpeedupNone\ 倍和 \PpMavraSpeedupPrivate\ 倍，同时答对 \PpMavraAcc\% 的问题，后两者为 \PpNoneAcc\% 和 \PpPrivateAcc\%。差别在于探索发生在哪里。在 \system\ 中，最先遇到某个指标的会话探索并发布，每次运行为五个指标一共提取 \PpMavraLearns\ 次；此后智能体都复用：\PpMavraReused\% 的问题执行共享的定义。指标学会之后，后一半智能体每题用 \PpMavraLateTokK\,k token、\PpMavraLateS\ 秒，比无记忆（\PpNoneLateTokK\,k token、\PpNoneLateS\ 秒）少 \PpMavraLateTokXNone\ 倍 token、快 \PpMavraLateSpeedupNone\ 倍。单智能体记忆每次运行提取 \PpPrivateLearns\ 次，却只在 \PpPrivateReused\% 的问题上复用，因为学会某个指标的智能体很少再问它：每个智能体都为学习付出代价，得到复用的却很少。它后来的智能体每题仍要 \PpPrivateLateTokK\,k token、\PpPrivateLateS\ 秒。}

\bi{\emph{What is shared decides correctness.} Example retrieval shares as well, and on unchanged data it saves as much: \PpTrajTotalTokM\,M tokens over \PpAgents\ agents, \PpTrajLateTokK\,k tokens per late question, and \PpTrajAcc\% correct. The restatement separates the two. Example retrieval hands every agent the SQL of an earlier session, which now counts restated sales twice; its agents answer \PpTrajChangeAcc\% of the returning questions, and every wrong answer is \PpTrajChangeOverMin--\PpTrajChangeOverMax\% too high. \system\ repairs each affected definition once for all agents, with \PpMavraMaintS\,s of database time, and its agents answer \PpMavraChangeAcc\% at \PpMavraChangeTokK\,k tokens per question. Single-agent memory repairs every agent's copy of a definition separately and spends \PpPrivateMaintS\,s of database time on it; without memory, agents explore the changed data again and answer \PpNoneChangeAcc\%.}
{\emph{共享什么决定了正确性。}示例检索同样在共享，数据不变时省下的也一样多：\PpAgents\ 个智能体共用 \PpTrajTotalTokM\,M token，后来的智能体每题 \PpTrajLateTokK\,k token，答对 \PpTrajAcc\%。更正把两者分开。示例检索把以往会话的 SQL 交给每个智能体，而这些 SQL 现在把被更正的销售算了两次；它的智能体只答对 \PpTrajChangeAcc\% 的回访问题，每个错误答案都偏高 \PpTrajChangeOverMin--\PpTrajChangeOverMax\%。\system\ 为所有智能体对每个受影响的定义只修复一次，用 \PpMavraMaintS\ 秒数据库时间，其智能体答对 \PpMavraChangeAcc\%，每题 \PpMavraChangeTokK\,k token。单智能体记忆要分别修复每个智能体手中的定义副本，为此花 \PpPrivateMaintS\ 秒数据库时间；没有记忆时，智能体在变化后的数据上重新探索，答对 \PpNoneChangeAcc\%。}
