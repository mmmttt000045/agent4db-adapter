\subsection{\bt{Repair and its boundary}{修复及其边界}}
\label{sec:repair-eval}
\bi{\emph{Where the regression test compares (Q3).} The agent's learning SQL was judged correct only on the data of learning time, so \system\ runs it and the replacement as of that time. With this test \system\ repairs every affected definition under status-change rows (\RpCurStatusCond\ of \RpCurStatusN\ questions correct) and restatements (\RpCurRevisionCond\ of \RpCurRevisionN) and answers \RpCurDimhistCond\ of \RpCurDimhistN\ SCD Type 2 questions. Run on current data (the last bar of each panel in Figure~\ref{fig:replay}), the test refuses correct fixes wherever a restatement or SCD Type 2 change touches the learning period, because the agent's SQL is itself stale there: \RpCurPairOther\ instead of \RpCurPairCond\ of the \RpCurPairN\ questions are answered (\RpCurDiff\ points fewer, 95\% cluster-bootstrap interval \RpCurDiffLo--\RpCurDiffHi), all of the difference in invalidated questions; a gold-SQL reference that anticipates the distinguishing columns answers \RpGoldPairOther.}
{\emph{回归测试在哪里比较（Q3）。}智能体的学习 SQL 只在学习时刻的数据上被判过对，所以 \system\ 以学习时刻为基准，把它与替代修订一起作 as-of 查询。用这个测试，\system\ 在状态流水（\RpCurStatusN\ 道题中答对 \RpCurStatusCond\ 道）与更正保留旧行（\RpCurRevisionN\ 道中 \RpCurRevisionCond\ 道）下修复了每一个受影响的定义，缓慢变化维（类型 2）的 \RpCurDimhistN\ 道题答对 \RpCurDimhistCond\ 道。在当前数据上比较时（图~\ref{fig:replay} 每个面板的最后一条），凡更正保留旧行或缓慢变化维（类型 2）触及学习期之处，智能体的 SQL 本身已经过期，测试便拒绝正确的修复：\RpCurPairN\ 道题中只答对 \RpCurPairOther\ 道而不是 \RpCurPairCond\ 道（少 \RpCurDiff\ 个百分点，按库整群自助 95\% 区间 \RpCurDiffLo--\RpCurDiffHi），差别全部是失效的题；预先写入区分列的标准答案参照答对 \RpGoldPairOther\ 道。}

\bi{\emph{Ambiguous fixes.} The backup-copy change appends a full copy of the returns table, marked by a source column, that keeps the old amounts of corrected returns; filters on either source restore one row per return without losing returns. Without the uniqueness rule, repair takes the first filter it finds, the backup, and a gold-SQL reference that already filters on the primary source accepts it: the published revision answers two of four new questions wrongly for both return metrics. With the rule, repair finds both filters and invalidates the definitions under either reference, and replaying \system\ with the rule changes none of the \RpCondN\ outcomes under either reference, because the status-change, restatement, and SCD Type 2 fixes are unique.}
{\emph{有歧义的修复。}备份副本变化追加一整份退货表的副本（以来源列标记），副本保留被更正退货的旧金额；按任一来源过滤都能使每笔退货恰好一行且不丢退货。没有唯一性规则时，修复取搜索到的第一个过滤，即备份，而预先按主数据来源过滤的标准答案参照会接受它：发布的修订在两个退货指标的 4 道新题中都答错 2 道。有了唯一性规则，修复会找到两个过滤，在任一参照下都使定义失效；打开该规则后重新回放 \system，两种参照下 \RpCondN\ 道题的结果都没有任何变化，因为状态流水、更正保留旧行与缓慢变化维（类型 2）的修复都是唯一的。}

\bi{\emph{Availability during repair.} Rejecting requests that arrive while a repair runs makes \WrDefOff\ of \WrUses\ simultaneous uses (eight agents using 19 definitions before and after each of four updates, three runs) unavailable under the full recheck and \WrCondOff\ under \system; coalescing them with the running repair removes all of them at the same total waiting time and database work.}
{\emph{修复期间的可用性。}若拒绝修复进行中到达的请求，同时到达的 \WrUses\ 次使用（8 个智能体在 4 次更新前后各使用 19 个定义一次，3 轮）中，整定义重查有 \WrDefOff\ 次不可用，\system\ 有 \WrCondOff\ 次；把它们与进行中的修复合并后，不可用全部消失，总等待时间与数据库工作量不变。}
