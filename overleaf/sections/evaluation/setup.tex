\subsection{\bt{Questions and setup}{问题与设置}}
\bi{The evaluation follows the responsibilities of the layer. Reliance: (Q1) do maintained definitions stay correct under data-only changes, independently of what agents learned? (Q2) Does use-time enforcement hold under concurrent writes, and at what cost? Maintenance: (Q3) when does repair restore a broken definition, and when must it invalidate it? (Q4) What does maintenance cost, and which part of the savings requires typed conditions? Value for consumers: (Q5) what does maintained shared memory do for LLM agents end to end, against exploring alone and retrieving examples? Improvement: (Q6) does an optimization sweep find cheaper equivalent revisions that consumers adopt? Q1--Q4 are answered at the system level, without LLMs, where definitions are fixed and only maintenance varies; Q5 and Q6 run complete agents. The machine has 48 Hygon cores and 98\,GiB RAM. PostgreSQL 18.6 runs in disposable isolated databases with WAL and fsync disabled. The synthetic retail fixture uses TPC-DS-style column names; with one million store-sales rows it contains about 396,000 returns and 500,000 catalog-sales rows, and each study states its scale. Table~\ref{tab:ladder} lists the compared methods, the question each answers, and the studies in which it appears. Revalidation methods share conditions, repair, regression test, and request coalescing. The regression test compares with the agent's own learning SQL as of learning time, except that the full recheck per definition uses the benchmark's gold SQL end to end, where \system\ with the gold-SQL reference answers the same as \system\ (Section~\ref{sec:scenarios}).}
{评估按这一层承担的职责展开。依赖：（Q1）维护后的定义能否在纯数据变化下保持正确，且不受智能体学到什么的影响？（Q2）存在并发写入时，使用时的强制保证是否成立，代价如何？维护：（Q3）修复何时能恢复被破坏的定义，何时必须使定义失效？（Q4）维护代价如何，节省中哪一部分需要类型化条件？对使用者的价值：（Q5）与独自探索和检索示例相比，维护后的共享记忆在端到端上对大模型智能体有何作用？改进：（Q6）一轮优化能否找到更省的等价修订，使用者是否采用？Q1--Q4 在系统层回答（不调用大模型）：定义固定，只改变维护方式；Q5 和 Q6 运行完整的智能体。实验机有 48 核 Hygon 和 98\,GiB 内存。PostgreSQL 18.6 在可丢弃的隔离库中运行，关闭 WAL 与 fsync。合成零售数据采用 TPC-DS 风格列名；100 万行门店销售对应约 39.6 万行退货和 50 万行目录销售，各实验分别说明其规模。表~\ref{tab:ladder} 列出被比较的方法、每个方法回答的问题及其所在实验。各重验证方法共用条件、修复、回归测试与请求合并。回归测试以智能体自己的学习 SQL 按学习时刻比较，只有整定义重查在端到端实验中使用基准的标准答案 SQL，而以标准答案作参照的 \system\ 在那里与 \system\ 答对的题数相同（第~\ref{sec:scenarios} 节）。}
