\subsection{\bt{Controlled metric studies}{受控指标实验}}
\label{sec:metric-setup}
\bi{The controlled studies ask whether sharing beats private memory with the same mechanisms (Q1), how consumers share validation and maintenance (Q3), and whether reuse persists after changes (Q4); Section~\ref{sec:sharing-eval} addresses agent work (Q2). The server has 48 cores, 98\,GiB RAM, and PostgreSQL 18.6. The population study uses TPC-DS SF1 (24 tables, 2.9 million store-sales rows). Held-out and change studies use TPC-DS-style synthetic retail data (one million sales, 396,000 returns, 500,000 catalog sales) and TPC-H SF1.}
{受控研究考察：共享是否优于同机制的私有记忆（Q1），使用者如何共享验证维护（Q3），变化后能否继续复用（Q4）；第~\ref{sec:sharing-eval}节考察智能体工作量（Q2）。服务器为48核、98\,GiB内存、PostgreSQL 18.6。群体实验使用TPC-DS SF1（24表、290万行门店销售）；留出及变化实验使用TPC-DS式合成零售数据（100万销售、39.6万退货、50万目录销售）与TPC-H SF1。}
\bi{Five metrics each have two learning questions stating the definition and five scored forms: a new period, a period difference, the month with the highest metric value, the largest month-to-month increase, and months above the mean. TPC-DS supplies five template-derived metrics with the same forms. Reference SQL runs on the question's snapshot. Agents and extractor use \llmmodel{}, high effort, 20 turns, and a 60\,s SQL limit (120\,s on TPC-DS/TPC-H); compared methods share these settings and base tools. Table~\ref{tab:ladder} defines the memory-scope and maintenance ablations. All tokens include input and output; time spans the agent session. Population sharing cells run once; Figure~\ref{fig:fixed-sharing} uses three randomized blocks. The sharing and snapshot controls make no model calls.}
{五个指标各有两道给出定义的学习题，以及新期间、期间差值、指标值最高的月份、最大月度增量、高于月均值的月份五种计分题。TPC-DS选取五个模板指标使用同样题型。参考SQL在题目快照上执行。智能体与提取器使用\llmmodel{}、高推理强度、20轮、60秒SQL上限（TPC-DS／TPC-H为120秒），比较组共用这些设置与基础工具。表~\ref{tab:ladder}定义记忆作用域与维护消融。token计输入输出之和，时间覆盖智能体会话。群体共享单元运行一次，图~\ref{fig:fixed-sharing}采用三轮随机顺序运行；共享和快照对照不调用模型。}
