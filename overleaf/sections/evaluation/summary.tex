\bi{Table~\ref{tab:ablation} collects, for each part of \system, what happens when it is replaced by the usual alternative. The parts fall into three groups that mirror the three problems of Section~\ref{sec:introduction}. Sharing and the replay of the generated SQL make one agent's work transferable to all others: without sharing, every agent pays for learning, and without the replay, extraction errors reach every agent. Conditions, rechecks on data changes, unique repair, the as-of regression test, and same-snapshot validation keep the shared knowledge correct: each alternative either serves wrong answers or gives up questions that \system\ answers. Maintenance once and shared check results keep correctness cheap: verification by each agent costs every question, and checking each definition separately costs a multiple of the database time. No single part suffices, and none is redundant.}
{表~\ref{tab:ablation} 汇总了把 \system\ 的每一部分换成常见替代做法后的结果。这些部分分为三组，对应引言中的三个问题。共享与生成的 SQL 重放使一个智能体的工作可以迁移给所有其他智能体：没有共享，每个智能体都为学习付出代价；没有重放，提取中的错误会到达每个智能体。条件、数据变化时的重查、唯一修复、按学习时刻的回归测试与同快照验证让共享的知识保持正确：每种替代做法要么给出错误答案，要么放弃 \system\ 能回答的问题。一次性维护与共享的检查结果让正确性保持便宜：每个智能体自行核验会让每道题都多花代价，逐个定义检查则要多花数倍的数据库时间。没有哪一部分单独就够，也没有哪一部分是多余的。}
