\subsection{\bt{What each part of the design saves}{设计的每一部分省下了什么}}
\label{sec:ablation-eval}
\bi{Each part of \system\ earns its place when it is replaced by the usual alternative. Without shared definitions, an agent spends \PpNoneLateTokK\,k tokens and \PpNoneLateS\,s per question instead of \PpMavraLateTokK\,k and \PpMavraLateS\,s, and single-agent memory needs \PpPrivateTotalTokM\,M instead of \PpMavraTotalTokM\,M tokens for \PpAgents\ agents (\S\ref{sec:population-eval}). Per-agent copies need \PpPrivateMaintS\,s instead of \PpMavraMaintS\,s of database time after a restatement, agents that verify shared SQL themselves spend \AmVerifyExtraS\,s and \AmVerifyExtraTokK\,k tokens more per question, dropping definitions on every write costs \ScenRelearnTok\,M tokens of relearning per run, a full recheck per definition raises database time from \CbStagCondSix\% to 100\% at 19 definitions, and without optimization every agent's SQL is \OptSaveMean\% slower (\S\ref{sec:cost}). Definitions without conditions, retrieved as examples, are answered \PpTrajChangeAcc\% correctly after a restatement instead of \PpMavraChangeAcc\% (\S\ref{sec:changes-eval}).}
{把 \system\ 的每一部分换成常见的替代做法，都会付出代价。没有共享的定义，智能体每题花 \PpNoneLateTokK\,k token、\PpNoneLateS\ 秒，而非 \PpMavraLateTokK\,k、\PpMavraLateS\ 秒；单智能体记忆让 \PpAgents\ 个智能体用 \PpPrivateTotalTokM\,M 而非 \PpMavraTotalTokM\,M token（\S\ref{sec:population-eval}）。按智能体的副本在更正之后需要 \PpPrivateMaintS\ 秒而非 \PpMavraMaintS\ 秒数据库时间；自行核验共享 SQL 的智能体每题多花 \AmVerifyExtraS\ 秒、\AmVerifyExtraTokK\,k token；每次写入即丢弃定义，每次运行要花 \ScenRelearnTok\,M token 重新学习；整定义重查在 19 个定义时让数据库时间从 \CbStagCondSix\% 升到 100\%；不做优化，每个智能体的 SQL 平均慢 \OptSaveMean\%（\S\ref{sec:cost}）。没有条件、作为示例检索的定义，在更正之后答对 \PpTrajChangeAcc\%，而非 \PpMavraChangeAcc\%（\S\ref{sec:changes-eval}）。}
