\label{sec:ablation-eval}
\input{tables/ablation}
\bi{Table~\ref{tab:ablation} collects, for each part of \system, what happens when it is replaced by the usual alternative. Shared definitions turn an explored question into one SQL, and sharing them across agents lets one exploration serve every agent instead of the agent that made it. Repair, maintenance, and check results paid once keep the upkeep of shared knowledge far below the exploration it saves, and an optimization published once makes every agent's SQL faster. Conditions keep the saving valid: without them a shared memory either hands out stale SQL or must be relearned after every write.}
{表~\ref{tab:ablation} 汇总了把 \system\ 的每一部分换成常见替代做法后的结果。共享的定义把一道需要探索的题变成一条 SQL，跨智能体共享使一次探索服务所有智能体，而不只是探索它的那个智能体。只付一次的修复、维护与检查结果，使维护共享知识的代价远小于它省下的探索；一次发布的优化让每个智能体的 SQL 都更快。条件让节省保持有效：没有条件，共享记忆要么交出过期的 SQL，要么每次写入后都得重新学习。}
