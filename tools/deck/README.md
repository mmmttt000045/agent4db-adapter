# 汇报 PPT

`build-deck.js` 生成 `docs/mavra-system.pptx`：15 页中文 PPT，按一条主线讲 MAVRA：学到规则 → 记住它成立的条件 → 数据变化 → 使用前检查 → 安全则继续用 → 不安全则尝试修复 → 修不好则失效并通知。先用一页说清与 Text-to-SQL 的区别，再用示意的小账本（订单 001–003，600 / 850 / 650 元）引出问题，接实验的真实记录；系统部分按论文的三个问题（检查什么、何时检查、失败后怎么办）展开；最后是两页实验结果和一页保证边界。每页带讲稿备注，备注里可以用账本、管理员、拍照片、考试这类比喻，幻灯片正文用标准数据库术语并配一句通俗解释。

| 页 | 内容 |
| --- | --- |
| 1 | 标题 |
| 2 | Text-to-SQL 与 MAVRA：不同层次的问题；同一问题三次独立求解的记录（口径不在模式中） |
| 3 | 问题：示意账本（第一天 600 元；第二天订单更正后沿用规则 850 元，正确 650 元）+ 实验真实记录（三种更新，对照组） |
| 4 | MAVRA 做三件事，对应论文的三个问题；整条逻辑链 |
| 5 | MAVRA 放在哪里：系统架构图（`figures/overview-zh.png`）+ 工具与四类记忆 |
| 6 | 一条规则怎样存进去：学习任务、知识卡（给智能体看的 / MAVRA 保管的）、7 项准入检查的通俗解释 |
| 7 | 检查什么：四类验证条件（通俗解释、示意、检查方式）；充分性命题与它不保证的事 |
| 8 | 何时检查：表版本 + 验证结果缓存的时间线；惰性维护；为什么要在同一快照内执行（10:00:00/01/02 的竞争）；引理 1 |
| 9 | 读取与使用（`figures/lookup-zh.png`） |

| 11 | 一条定义的生命周期（`figures/lifecycle-zh.png`）+ 修订规则 |
| 12 | 完整的故事：数据更正之后三条共享定义怎样一起被修好（系统记录）；三种更新的结果 |
| 13 | 实验结果①：端到端（7 种方法 × 数据未变 / 11 种更新 / 5 种破坏性更新 / 单位变化 / 备份副本） |
| 14 | 实验结果②：系统层（配对回放合成与 TPC-DS、同快照验证、修复的回归基准、维护成本） |
| 15 | 保证边界（能做什么 / 做不到什么）与三句话总结 |

第 3、7、8、10 页的小账本和时刻为示意，页脚注明；其余数字来自存档记录或论文宏。

例子页的数字都取自 noctis `results/scen-20261002/` 的存档：MAVRA 第 1 次运行 `dsv41flash-r1-g3fix--snap`（第 2 页用 r1–r3），对照组 `dsv41flash-r{1,2,3}-g3fix--schema`（只在表结构变化时失效），不共享指标定义的智能体 `dsv41flash-r1-a`、`r2-b`、`r3-a`（`middle`），回归测试对照 `dsv41flash-r1-g3fix--exref`。第 13 页的准确率与 `overleaf/gen/scen-ds.tex` 的 `\Ds*` 宏一致；第 14 页与 `\Rp*`、`\Tr*`、`\Sn*`、`\CbStag*` 宏一致（`exp/2026-10-02-cache-baseline-tpcds`、快照压力测试、`exp/2026-10-03-session-latency`）。题目中的年份略去（合成数据的日期在 2000–2002 年）。

三张图由 `tools/figures/overview.py`、`lookup.py`、`lifecycle.py` 画成，按幻灯片尺寸设计（300 mm 宽，12–15 pt 字），用标准的数据库术语：指标定义、共享记忆、验证条件、验证结果缓存、表版本、快照、修订 v1/v2、失效、准入检查、修复搜索、谓词、回归测试，不用论文里的符号、自造词或口语化说法。改图后先在 noctis 上重画并转成 PNG，再在本机生成 PPT：

```bash
# noctis，仓库根目录
python3 tools/figures/build.py --deck
cd tools/deck/figures && for f in *.pdf; do pdftoppm -r 300 -png -singlefile $f ${f%.pdf}; done

# 本机（把 tools/deck/figures 取回后）
cd tools/deck
npm ci          # 只需一次，pptxgenjs 4.0.1
npm run build   # 写 docs/mavra-system.pptx；或 node build-deck.js --out 其他路径
```

图中数值取自同一次运行：学习题 3 月门店营业额 1357.0 万；数据更正后 9 月 1293.3 万（不处理时 1430.1 万）。字体为 Microsoft YaHei；在 Linux 上用 LibreOffice 预览时由 Noto Sans CJK SC 代替。
